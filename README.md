# Assignment Overview

This repository contains my solutions for **Module 4: Assignment-1 (Problem Solving with TypeScript & OOP)**. The assignment covers core TypeScript concepts from Modules 1, 2, and 3, including basic types, optional/default/rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and Object-Oriented Programming.

All 8 problem-solving tasks are implemented in a single file, [`solutions.ts`](./solutions.ts):

1. `multiplyValue` - optional parameter with a default multiplier
2. `processInput` - union types and type narrowing with `typeof`
3. `formatCoordinate` - readonly tuple parameter
4. `concatenateArrays` - generics with rest parameters
5. `Course` interface and `getPopularCourses` - filtering without mutation
6. `pluckValues` - generics with the `keyof` constraint
7. `Employee` and `Manager` classes - inheritance with `protected` and `private` modifiers
8. `validateAgeAsync` - Promises with `setTimeout` and error rejection
